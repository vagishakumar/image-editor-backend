# AI Image Editor Backend

This is the backend service for the **AI Image Editor** project, built using **Node.js** and **Express.js**. It handles **AI-driven image processing tasks**, **user authentication**, and **file storage**, enabling advanced editing features for the frontend application.

## Features

- Remove Background
- Change Background
- Erase Object
- Modify Image by Marking and Prompting
- Generate Image with Prompt
- Blur Background
- Remove Foreground
- Increase Resolutions

## Tech Stack

- **Node.js**
- **Express.js**
- **Multer** (File Upload)
- **Sharp** (Image Processing)
- **Cloudinary** (Cloud Storage)
- **dotenv** (Environment Variables)
- **serverless-http** (Netlify Integration)
